§1工具链前置:Vitis HLS 三件套

HLS-1csim → cosim → export,与 dataflow/接口 pragma

学什么csim(C 级功能验证)/ cosim(RTL 联合仿真)/ export(打包成 IP)的分工;DATAFLOW 进程流水;ap_ctrl_none 自由运行核与纯 AXI4-Stream 口意味着什么。 为什么rocev2 是 HLS 核,Stage A 全程在这套流程里;DCL gzip CU(平台可用期 ④ 已定版 8 核/16KB)同样是 ap_ctrl_none 纯流式——同一套心智模型。④ 的教训补一课:csim 绿 ≠ RTL 绿(1 核配置 csim 通过但 RTL 死锁,FIFO 深度随核数缩放而 csim 流无界)。 动手把 hls/rocev2 的 csim 跑通(= Stage A 的操作 1–2),记录 2025.2 与 2022.2 的行为差异进决策日志。 入口hls/rocev2/CMakeLists.txt + make.tcl.in(仓库自带构建流程,以它为准)

§2fpga-network-stack(协议引擎)

2.1 仓库与分支事实

仓库github.com/fpgasystems/fpga-network-stack 分支coyote-TCP-RDMA——Coyote v2 以 submodule hw/services/network 引用的就是它(2024-02 重构后、BALBOA 同款核)。不要用 master 上的老 RoCE 或 coyote_v1 的旧核。BALBOA 论文钉的 commit 是 9eda6ce;我们钉死 20633d03(Stage A 决策) 规模全仓 392 文件;RoCE 核 HLS + SV 混合 许可BSD-3(仓库 LICENSE 为准)

§3Corundum(NIC 载体)

3.1 资产与 app_block 挂点

已有资产:VCU118 fpga_100g bitstream 已构建(rev100,时序收敛),基线占用 LUT 6.66% / BRAM 11.76% / URAM 4.69% → >88% 器件余量留给我们的逻辑。集成走 mqnic_app_block——Corundum 文档明确它是数据面内自定义包处理的预期挂点:

接口组信号用途(本平台)
MAC 直连流s/m_axis_direct_tx/rxTX/RX 时钟域、最低延迟;暂不用
核时钟同步流s/m_axis_sync_tx/rx主用:RoCE 帧从 m_axis_sync_tx 注入;s_axis_sync_rx 上按 UDP:4791 过滤截获,其余流量透传给 mqnic 原生路径
聚合接口流s/m_axis_if_tx/rx接口级聚合;暂不用
控制s_axil_app_ctrldoorbell 垫片的 BAR 落点:WR 字段寄存器、QP 配置、计数器读回
DMADMA read/write desc + RAML0 阶段用于把 payload 从 host 搬进 staging;L1 阶段升级为 WQE fetch

启用需在构建参数打开对应的 APP_AXIS_SYNC_ENABLE 等开关(Stage D 检查项)。注意 Corundum 主线自 2023-12 起休眠——遇 shell 问题以自己读源码为准,别指望上游响应。

Stage D 实测更新载体决策最终落在 (b) 裸 CMAC + jtag_axi 最小 shell:rev100 三层锁(250MHz 主时钟 = PCIe user_clk、mmcm_rst=pcie_user_reset、CMAC 阀门唯一主人是 PCIe BAR)在板不插槽的约束下不可救。app_block 挂点知识仍然有效——它是将来 L1/PCIe 阶段的回归路径;shell 只搬运验证过的组件。详见指南仪表盘 07-17 载体决策行。

§4BALBOA(参考设计与对标对象)

BALBOA 在本项目文档里被反复引用但此前没有独立介绍——本节把散落各处的事实聚拢成一页。

是什么arXiv 2507.20412(ETH fpgasystems 组):基于与我们同一条 fns coyote 分支的重构核(reconstructed core)发表的 RoCE v2 FPGA 参考设计。论文钉 commit 9eda6ce;我们钉 20633d03——同核血统,这正是它作为对标对象的价值。 实现范围仅 WRITE + READ,无 SEND/ATOMICS——与我们"WRITE-only 够用"的科研范围判断相互印证。 流控ACK 时钟化的按请求计信用,不依赖 PFC;论文在有损交换网上跑通——我们的点对点环回是更弱的要求。 ICRC重造为 512/320/32-bit 并行流水,论文数据约 12.5K LUT(占核内 28%)——ICRC 是这类栈的最大单体开销之一。 重传重传缓冲设计在 HBM 通道上——VCU118 无 HBM,平台已把重传缓冲再安置到 URAM(平台可用期 ③,B9 仿真闭案)。读它的设计时注意这条移植差异。 可比数字U55C 重构核约 44K LUT / 101 BRAM(同 UltraScale+ 工艺,可比;我们的构建含 jtag_axi + staging + 胶水,会有出入)。Fig-5 分段延迟插桩方法学(各流水段 first-byte-in→first-byte-out 的 cycle 计数)是我们板级延迟测量的模板。注意:数字系论文图表像素测量,一律标"约"。
竞争风险(= 指南已知雷 #6)BALBOA 论文原文:正在做"line-rate compression and decompression logic cores"。每季度盯 fpgasystems 仓库与 arXiv;我们的研究段 novelty 钉在 dual-length verbs 语义 + 实测 per-WR gate,不赌"首个内联压缩"。

深读材料(三层对比表、CX-5 互操作 14 项检查单)尚未落盘;本节即目前对 BALBOA 的唯一成文出处。
